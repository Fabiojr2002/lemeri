# Luméri Perfumes Árabes / Auraé Parfums

Landing page moderna e sofisticada para e-commerce de fragrâncias de luxo, com design editorial, estética minimalista e acabamento premium.

## ✨ Destaques do Projeto

- **Hero Section Cinemática:**
  - Layout inspirado em editoriais de moda e alta perfumaria (*Auraé Parfums*).
  - Tipografia de alto padrão com Google Fonts (*Cormorant Garamond* e *Jost*).
  - Botões de ação em formato de pílula (*Pill buttons*) com micro-interações suaves.
  - Card flutuante de prova social com efeito *glassmorphism*, avaliação 4.9/5 e avatares reais.
- **Barra de Navegação Dinâmica:**
  - 100% transparente no topo integrado ao cenário.
  - Transição suave para cabeçalho translúcido com *backdrop-filter blur* ao rolar a página.
  - Menu centralizado e ícones vetoriais modernos (*Lucide Icons*).
- **Catálogo & E-commerce:**
  - Vitrine de produtos com cálculo de carrinho e contador em tempo real.
  - Seções de categorias, benefícios (frete grátis, 100% originais) e newsletter.
- **Tecnologias:**
  - HTML5 Semântico
  - CSS3 Moderno (Custom Properties, Flexbox, Grid, Glassmorphism)
  - Vanilla JavaScript ES6+
  - [Lucide Icons](https://lucide.dev/)

## 🚀 Como Executar Localmente

1. Clone o repositório:
```bash
git clone https://github.com/Fabiojr2002/lemeri.git
```

2. Abra o arquivo `index.html` em qualquer navegador moderno ou utilize um servidor local:
```bash
python -m http.server 3000
```
Acesse `http://localhost:3000` no seu navegador.
